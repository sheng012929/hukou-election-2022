2022 新竹縣議員湖口鄉投開票所票數比較網站

網站入口：index.html

本網站為純靜態單頁網站，不需要建置或伺服器端程式。將 index.html 上傳至支援靜態網站的託管服務，即可透過服務提供的公開網址分享。

GitHub Pages（使用既有 GitHub repository）大致步驟：
1. 將 index.html 放在 repository 根目錄，提交並推送。
2. 在 repository 的 Settings > Pages 選擇部署來源與分支。
3. 等待 Pages 完成部署後，複製公開網址分享。

資料來源與下載功能已內嵌於頁面中。CSV 下載會在瀏覽器本機產生檔案。
